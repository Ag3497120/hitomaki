# ひと巻き · Between Rolls

[English](README.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md) · [한국어](README.ko.md) · [Español](README.es.md)

**ひと巻きの間に、どんな時間を過ごそう。**

トイレットペーパーを交換する瞬間を、過ぎた時間に気づき、次の小さな目標を決めるきっかけにするアプリです。

[アプリを開く](https://ag3497120.github.io/hitomaki/) · [English README](README.md) · [Issueで議論する](https://github.com/Ag3497120/hitomaki/issues)

## 使い方

1. ロールの開始を記録し、読書・散歩・大切な人への連絡など、小さな目標を選びます。
2. 交換のときに前の目標を振り返ります。
3. 最初の1ロールを使い切ると、実測間隔から1年・10年・30年をロールに換算する画面が開きます。
4. 希望する場合だけLife Viewを開き、自分で選んだ基準年齢までの時間を確認できます。寿命の予測ではありません。
5. 次の目標を決めて保存します。履歴の確認と直前の交換の取り消しもできます。

日本語・英語・中国語（簡体字）・韓国語・スペイン語に対応しています。言語設定から居住国や生活習慣は推定しません。国ごとに自然な表現になっているかは、今後の当事者・母語話者レビューで改善します。

## 数字の根拠

```text
平均ロール間隔（日） = 完了したロールの実測日数の合計 ÷ 完了本数
年間換算本数         = 365.2425 ÷ 平均ロール間隔
読書への換算         = 経過日数 × 設定した1日あたりの分数 ÷ 1ページあたりの分数
```

記録途中のロールは平均に入れません。1本だけの値は初期推定と表示します。3本以上では、直近30日に交換を終えたロールの「開始から終了までの全区間」の平均も比較できます。

読書の初期設定「1日10分・1ページ2分」は変更できる仮定です。実際に読んだ量や、国別の平均を表しません。年・人生のロール表示も、設定と観測から作る時間軸です。

Life Viewは、設定時点の整数年齢と基準年齢の差に365.2425日を掛け、設定日に固定した目安です。誕生日に基づく厳密な残日数や死亡日の予測ではなく、画面を開くたびに目安の日付が先送りされることもありません。

[調査方針](docs/research-policy.md)とIssueテンプレートには、出典・仮定・範囲・確かさ・バージョンを記載する欄があります。個人実測と家庭実測は対象が違うため、混同しません。「5本で個人プロファイルへ切り替える」などは検討例で、確定済みの仕様ではありません。

## 保存とプライバシー

記録・目標・メモ・言語設定・任意の年齢設定は、このブラウザーのlocalStorageに保存します。記録を受け取るアプリ側サーバー、アカウント、解析SDKはありません。配信元のGitHub Pagesは通常のアクセス情報を扱う場合があります。

ブラウザーのデータを消すと記録も失われる場合があります。端末間同期・バックアップ・インポート／エクスポートは未実装です。

**以前のchatgpt.site版とGitHub Pages版は保存先が別です。過去の記録は自動移行されません。** 以前の記録を見たい場合は元のサイトを残してください。同じ `ag3497120.github.io` 配下のサイトは同一オリジンのため、機微な個人情報の保管場所としては使わないでください。

## 開発と公開

Node.js 24（最低22.18）とnpmを使用します。

```sh
npm ci
npm run dev
npm test
npm run lint
npm run typecheck
npm run build:pages
```

GitHub Pages向けの公開ファイルは `out/` に生成されます。`main` にpushするとGitHub Actionsが検証と公開を実行します。PRは検証のみ行います。ローカルでの静的プレビュー、別名のリポジトリへの対応、既存Sitesビルドについては[英語版README](README.md#development)を参照してください。

自動検証は計算・保存データ・言語辞書・静的出力を対象としています。ブラウザー操作やアクセシビリティの監査、母語話者によるレビューは今後の課題です。
