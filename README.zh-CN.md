# 一卷时光 · Between Rolls（ひと巻き）

[English](README.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md) · [한국어](README.ko.md) · [Español](README.es.md)

**换一卷纸，也给自己一个回望生活的时刻。**

用完一卷卫生纸，是日常生活中一个摸得着的时间刻度。这个小应用邀请你在换卷时看看这段时间如何度过，再为下一卷选一个小目标：读一章书、散一次步，或联系一个在乎的人。

[打开应用](https://ag3497120.github.io/hitomaki/) · [参与讨论](https://github.com/Ag3497120/hitomaki/issues)

## 怎么用

1. 记录一卷纸的开始时间，选一个小目标。
2. 平时可以查看已经过去的时间，也可以按自己设定的阅读时间换算成页数。
3. 换卷时回顾上一个目标。完成第一卷后，才会展开一年、十年、三十年的时间尺度。
4. 如果愿意，可以主动打开 **Life View**，自行选择一个参考年龄。这里展示的是你选定的时间范围，不是在预测寿命。
5. 为下一卷设定目标并保存。之后可以查看历史，也可以撤销最近一次换卷记录。

应用支持**日语、英语、简体中文、韩语和西班牙语**，语言选择保存在本机。界面语言不代表居住国家，也不能用来推断家庭习惯。各地区的表达仍需要熟悉当地语境的使用者和母语者参与审校。

## 数字从哪里来

当前版本只用记录中的开始和结束时间计算，没有预设“某个国家一卷纸能用几天”，也不会把共用纸卷的间隔当成个人用纸量。

```text
平均间隔（天） = 已完成纸卷的间隔天数之和 ÷ 已完成卷数
每年换算卷数   = 365.2425 ÷ 平均间隔
N 年换算卷数   = N × 365.2425 ÷ 平均间隔
阅读换算页数   = 经过的天数 × 每天设定的阅读分钟数 ÷ 每页设定的分钟数
```

正在使用的纸卷不计入平均值。只有一卷记录时，结果会标为初步估算。完成至少三卷后，近期比较使用最近30天内结束的纸卷各自的**完整间隔**。计算保留精度，到显示时才取整。

默认的“每天10分钟、每页2分钟”只是可修改的示例假设，并非阅读实绩或人群统计。纸卷网格也是时间尺度的示意，不是实际已用纸量的记录。

Life View用“参考年龄减去当前整数年龄”乘以365.2425天，将目标时间固定在保存年龄设置的那一天。它不使用生日，不能提供精确到生日的剩余天数。剩余卷数是这一参考时间范围内的天数除以记录的平均间隔；每次打开页面不会把目标日期向后推移，也不会发送死亡倒计时提醒。

纸卷规格、家庭共享、旅行和多个卫生间都可能改变换卷间隔。这些因素如何解释，仍在公开讨论中。

## 隐私与保存

目标、笔记、历史、语言和可选年龄设置保存在当前浏览器的 `localStorage`。应用没有账号、分析SDK，也没有接收这些记录的服务器接口。GitHub Pages负责传送网页文件，可能依其政策处理常规访问元数据。

- 尚不支持跨设备同步、备份或导入／导出。清除浏览器数据可能删除记录；无痕模式不一定保留记录。
- **原来的chatgpt.site版与GitHub Pages版属于不同来源，记录不会自动迁移。** 需要查看旧记录时，请保留原站点。
- 同一 `ag3497120.github.io` 来源下的其他项目共用浏览器存储的安全边界。请勿把本应用作为敏感个人信息的保管处。
- GitHub图标只会在新标签页打开代码仓库，不会把日记发送到GitHub。

## 本地开发与部署

使用 **Node.js 24**（最低22.18）和npm。

```sh
npm ci
npm run dev
npm test
npm run lint
npm run typecheck
npm run build:pages
```

技术栈为React 19、TypeScript、Vinext/Vite、Tailwind CSS和Base UI。开发时打开终端给出的本地地址。Pages构建使用 `/hitomaki` 路径，只把公开静态文件整理到 `out/`。

本地预览静态版本：

```sh
mkdir -p .preview/hitomaki
cp -R out/. .preview/hitomaki/
python3 -m http.server 4173 --directory .preview
```

打开 `http://localhost:4173/hitomaki/`。另一个命令 `npm run build` 保留原有Sites/Cloudflare Worker构建，`npm start` 在本地运行该输出。`.openai/hosting.json` 属于原Sites项目，Pages部署不使用它进行授权。

[GitHub Actions](.github/workflows/pages.yml)在推送到 `main` 或手动运行时进行检查、构建与部署；拉取请求只检查、不部署。仓库Settings → Pages的发布方式需选择GitHub Actions，无需应用密钥。若更换仓库名或使用自定义域名，需要同步修改 `next.config.ts` 的路径、`app/layout.tsx` 的图标路径、`scripts/build-pages.mjs` 的输出整理路径及公开链接。

自动检查覆盖记录、非法输入、撤销、语言回退和词典一致性、平均值、年龄参考时间与网格上限，以及静态资源引用。浏览器交互、无障碍审计和母语审校仍有待完成。

GitHub标志来自[Octicons](https://github.com/primer/octicons)，按其[MIT许可](docs/octicons-LICENSE.txt)使用。各依赖保留各自的许可。
